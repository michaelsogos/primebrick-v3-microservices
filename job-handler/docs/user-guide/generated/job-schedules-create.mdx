Configure when this job runs.

This page is delivered by the owning module as a remote component — its content mounts inside the shared shell.

The page is visible with the `access.system.job.job-schedules.create` grant.

## Pages routes

- `/system/job/job-schedules` — List, search and manage all job schedules.
- `/system/job/job-schedules/create` — Create a new job schedule. *(this page)*

## What you can do here

### How to create a new job schedule
1. On the **Job Schedules** list page, click **New** in the toolbar.
2. Fill in the fields below — required: **Name**, **Schedule**, **Lane**, **Target service**, **Target action**.
3. Click **Save** — the new job schedule is created.
