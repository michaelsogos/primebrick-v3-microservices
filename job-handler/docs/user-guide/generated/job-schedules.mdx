List, search and manage all job schedules.

Each row shows the Job Name, the Source Queue, the Service, the Kind, the Armed By, the Cadence, the Type, the Status, the Anomaly, the Run Stats, the Enabled at, the Next run, the Updated at, plus the status flags Enabled.

The page is visible with the `access.system.job.job-schedules` grant.

| Column | Visible | Sortable | Filterable | Notes |
|--------|---------|----------|------------|-------|
| **Job Name** | yes | yes | yes |  |
| **Source Queue** | yes | yes | yes | The queue this schedule is armed on — the scheduler picks up due work here. Schedules created by the system listen on service-owned queues. |
| **Service** | yes | yes | yes |  |
| **Kind** | yes | yes | yes |  |
| **Cadence** | yes | yes | no |  |
| **Trigger** | no | yes | yes |  |
| **Type** | yes | yes | no |  |
| **Destination Event** | no | yes | yes | The event fired when the schedule comes due: the operation the run performs (e.g. send an email). Available destinations depend on the active services. |
| **Status** | yes | yes | yes |  |
| **Enabled** | yes | no | no |  |
| **Anomaly** | yes | no | no |  |
| **Run Stats** | yes | no | no |  |
| **Enabled at** | yes | yes | yes |  |
| **Next run** | yes | yes | yes |  |
| **UUID** | no | yes | yes |  |
| **Lane** | no | yes | yes |  |

- The Job Name column is shown by default and can be sorted and filtered.
- The Source Queue column is shown by default and can be sorted and filtered — the queue this schedule is armed on — the scheduler picks up due work here. Schedules created by the system listen on service-owned queues.
- The Service column is shown by default and can be sorted and filtered.
- The Kind column is shown by default and can be sorted and filtered.
- The Cadence column is shown by default and can be sorted but not filtered.
- The Trigger column is hidden by default and can be sorted and filtered.
- The Type column is shown by default and can be sorted but not filtered.
- The Destination Event column is hidden by default and can be sorted and filtered — the event fired when the schedule comes due: the operation the run performs (e.g. send an email). Available destinations depend on the active services.
- The Status column is shown by default and can be sorted and filtered.
- The Enabled column is shown by default and cannot be sorted or filtered.
- The Anomaly column is shown by default and cannot be sorted or filtered.
- The Run Stats column is shown by default and cannot be sorted or filtered.
- The Enabled at column is shown by default and can be sorted and filtered.
- The Next run column is shown by default and can be sorted and filtered.
- The UUID column is hidden by default and can be sorted and filtered.
- The Lane column is hidden by default and can be sorted and filtered.
- The Disabled at column is hidden by default and can be sorted and filtered.
- The Fired at column is hidden by default and can be sorted and filtered.
- The Expires at column is hidden by default and can be sorted and filtered.

## Actions

### Row actions

| Action | Status | Permission | What it does | Require Step-Up Auth |
|--------|--------|------------|--------------|----------------------|
| **create** | DISABLED | — | Creates a new job schedule | no |
| **update** | DISABLED | — | Opens the job schedule for editing | no |
| **delete** | DISABLED | — | Marks the job schedule as deleted but keeps it so it can be restored | no |
| **restore** | DISABLED | — | Brings a soft-deleted job schedule back | no |
| **purge** | DISABLED | — | Removes the job schedule forever | no |
| **audit history** | DISABLED | — | Shows the change history of the job schedule | no |

- Creating a new job schedule is not available on this page — no permission is declared for it on job schedules.
- Editing a job schedule is not available on this page — no permission is declared for it on job schedules.
- Soft-deleting a job schedule is not available on this page — no permission is declared for it on job schedules.
- Restoring a soft-deleted job schedule is not available on this page — no permission is declared for it on job schedules.
- Permanently deleting a job schedule is not available on this page — no permission is declared for it on job schedules.
- Viewing the change history of a job schedule is not available on this page — no permission is declared for it on job schedules.
