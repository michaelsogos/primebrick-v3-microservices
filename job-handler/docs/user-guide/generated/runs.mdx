List, search and manage all job runs.

The page is visible with the `access.system.job.runs` grant.

## What you can do here

### How to view the change history of a job run
1. Open the row actions menu on the job run and click **Audit history**.
2. The version history of the job run will appear on the right sheet panel.

## Actions

### Row actions

| Action | Status | Permission | What it does | Require Step-Up Auth |
|--------|--------|------------|--------------|----------------------|
| **create** | DISABLED | — | Creates a new job run | no |
| **update** | DISABLED | — | Opens the job run for editing | no |
| **delete** | DISABLED | — | Marks the job run as deleted but keeps it so it can be restored | no |
| **restore** | DISABLED | — | Brings a soft-deleted job run back | no |
| **purge** | DISABLED | — | Removes the job run forever | no |
| **audit history** | ENABLED | `_authenticated_admin` | Shows the change history of the job run | no |

- Creating a new job run is not available on this page — no permission is declared for it on job runs.
- Editing a job run is not available on this page — no permission is declared for it on job runs.
- Soft-deleting a job run is not available on this page — no permission is declared for it on job runs.
- Restoring a soft-deleted job run is not available on this page — no permission is declared for it on job runs.
- Permanently deleting a job run is not available on this page — no permission is declared for it on job runs.
- Viewing the change history of a job run is available on this page — every job run keeps a full version history and it requires the `_authenticated_admin` permission.
