List, search and manage all job runs.

Each row shows the Job Name, the Status, the Started at, the Finished at, the Duration, the Error Code, the Redeliveries, the Fire #, the Report.

The page is visible with the `access.system.job.runs` grant.

## Columns

| Column | Visible | Sortable | Filterable | Notes |
|--------|---------|----------|------------|-------|
| **Job Name** | yes | yes | yes |  |
| **Status** | yes | yes | yes |  |
| **Trigger** | no | yes | yes |  |
| **Scheduler** | no | yes | yes |  |
| **Duration** | yes | yes | yes |  |
| **Source Queue** | no | yes | yes |  |
| **Destination Event** | no | yes | yes |  |
| **Run As** | no | yes | yes |  |
| **Error Code** | yes | yes | yes |  |
| **Redeliveries** | yes | yes | yes |  |
| **Fire #** | yes | yes | no |  |
| **Report** | yes | yes | no |  |
| **UUID** | no | yes | yes |  |

- The Job Name column is shown by default and can be sorted and filtered.
- The Status column is shown by default and can be sorted and filtered.
- The Trigger column is hidden by default and can be sorted and filtered.
- The Scheduler column is hidden by default and can be sorted and filtered.
- The Duration column is shown by default and can be sorted and filtered.
- The Source Queue column is hidden by default and can be sorted and filtered.
- The Destination Event column is hidden by default and can be sorted and filtered.
- The Run As column is hidden by default and can be sorted and filtered.
- The Error Code column is shown by default and can be sorted and filtered.
- The Redeliveries column is shown by default and can be sorted and filtered.
- The Fire # column is shown by default and can be sorted but not filtered.
- The Report column is shown by default and can be sorted but not filtered.
- The UUID column is hidden by default and can be sorted and filtered.

## Actions

### Row actions

| Action | Status | Permission | What it does | Require Step-Up Auth |
|--------|--------|------------|--------------|----------------------|
| **create** | DISABLED | — | Creates a new job run | no |
| **update** | DISABLED | — | Opens the job run for editing | no |
| **delete** | DISABLED | — | Marks the job run as deleted but keeps it so it can be restored | no |
| **restore** | DISABLED | — | Brings a soft-deleted job run back | no |
| **purge** | DISABLED | — | Removes the job run forever | no |
| **audit history** | DISABLED | — | Shows the change history of the job run | no |

- Creating a new job run is not available on this page — no permission is declared for it on job runs.
- Editing a job run is not available on this page — no permission is declared for it on job runs.
- Soft-deleting a job run is not available on this page — no permission is declared for it on job runs.
- Restoring a soft-deleted job run is not available on this page — no permission is declared for it on job runs.
- Permanently deleting a job run is not available on this page — no permission is declared for it on job runs.
- Viewing the change history of a job run is not available on this page — no permission is declared for it on job runs.
