List, search and manage all sequences.

Each row shows the Name, the Increment, the Start, the Current, the Next, the Pattern, the Current Sequence, the Next Sequence, the Time zone, the Renew Every, the Starts from, the revive slot, the Renews On.

The page is visible with the `access.system.job.settings.sequences` grant.

## What you can do here

### How to delete a sequence
1. Open the row actions menu on the sequence and click **Delete**.
2. Confirm the deletion in the dialog — the sequence is soft-deleted and can be restored.

### How to restore a deleted sequence
1. Set the deleted-records filter to **Deleted only** or **All records** to show recoverable records.
2. Open the row actions menu on the sequence and click **Restore**.
3. Confirm in the dialog — the sequence is active again.

### How to view the change history of a sequence
1. Open the row actions menu on the sequence and click **Audit history**.
2. The version history of the sequence will appear on the right sheet panel.

## Actions

### Row actions

| Action | Status | Permission | What it does | Require Step-Up Auth |
|--------|--------|------------|--------------|----------------------|
| **create** | DISABLED | `job.sequence.create.single` | Creates a new sequence | no |
| **update** | DISABLED | `job.sequence.update.single` | Opens the sequence for editing | no |
| **delete** | ENABLED | `job.sequence.delete.single` | Marks the sequence as deleted but keeps it so it can be restored | no |
| **restore** | ENABLED | `job.sequence.restore.single` | Brings a soft-deleted sequence back | no |
| **purge** | DISABLED | — | Removes the sequence forever | no |
| **audit history** | ENABLED | `job.sequence.read.audit` | Shows the change history of the sequence | no |

- Creating a new sequence is not available on this page — if enabled, it would require the `job.sequence.create.single` permission.
- Editing a sequence is not available on this page — if enabled, it would require the `job.sequence.update.single` permission.
- Soft-deleting a sequence is available on this page — marks the sequence as deleted but keeps it so it can be restored and it requires the `job.sequence.delete.single` permission.
- Restoring a soft-deleted sequence is available on this page — brings a soft-deleted sequence back and it requires the `job.sequence.restore.single` permission.
- Permanently deleting a sequence is not available on this page — no permission is declared for it on sequences.
- Viewing the change history of a sequence is available on this page — every sequence keeps a full version history and it requires the `job.sequence.read.audit` permission.

### Bulk actions

| Action | Status | Permission | What it does | Require Step-Up Auth |
|--------|--------|------------|--------------|----------------------|
| **delete** | ENABLED | `job.sequence.delete.bulk` | Marks the selected sequences as deleted | no |
| **restore** | ENABLED | `job.sequence.restore.bulk` | Restores the selected sequences | no |
| **duplicate** | DISABLED | — | Duplicates the selected sequences | no |
| **export** | ENABLED | `job.sequence.export.all` | Exports the list | no |

- Soft-deleting the selected sequences is available on this page — marks the selected sequences as deleted and it requires the `job.sequence.delete.bulk` permission.
- Restoring the selected sequences is available on this page — restores the selected sequences and it requires the `job.sequence.restore.bulk` permission.
- Duplicating the selected sequences is not available on this page — no permission is declared for it on sequences.
- Exporting the list is available on this page — exports the list and it requires the `job.sequence.export.all` permission.
