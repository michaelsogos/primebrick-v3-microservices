List, search and manage all qualifications.

Each row shows the Code, the Label translation, the Sort.

The page is visible with the `access.crm.qualifications` grant.

## Pages routes

- `/crm/qualifications` — List, search and manage all qualifications. *(this page)*
- `/crm/qualifications/create` — Create a new qualification.

## What you can do here

### How to create a new qualification
1. Click **New** in the toolbar.
2. Fill in the form — required: **10**, **0**, **1**, **2**.
3. Click **Save** — the new qualification is created.

### How to delete a qualification
1. Open the row actions menu on the qualification and click **Delete**.
2. Confirm the deletion in the dialog — the qualification is soft-deleted and can be restored.

### How to restore a deleted qualification
1. Set the deleted-records filter to **Deleted only** or **All records** to show recoverable records.
2. Open the row actions menu on the qualification and click **Restore**.
3. Confirm in the dialog — the qualification is active again.

### How to view the change history of a qualification
1. Open the row actions menu on the qualification and click **Audit history**.
2. The version history of the qualification will appear on the right sheet panel.

## Actions

### Row actions

| Action | Status | Permission | What it does | Require Step-Up Auth |
|--------|--------|------------|--------------|----------------------|
| **create** | ENABLED | `crm.qualification.create.single` | Creates a new qualification | no |
| **update** | DISABLED | `crm.qualification.update.single` | Opens the qualification for editing | no |
| **delete** | ENABLED | `crm.qualification.delete.single` | Marks the qualification as deleted but keeps it so it can be restored | no |
| **restore** | ENABLED | `crm.qualification.restore.single` | Brings a soft-deleted qualification back | no |
| **purge** | DISABLED | — | Removes the qualification forever | no |
| **audit history** | ENABLED | `crm.qualification.read.audit` | Shows the change history of the qualification | no |

- Creating a new qualification is available on this page — the create action opens the create form in the same tab and it requires the `crm.qualification.create.single` permission.
- Editing a qualification is not available on this page — if enabled, it would require the `crm.qualification.update.single` permission.
- Soft-deleting a qualification is available on this page — marks the qualification as deleted but keeps it so it can be restored and it requires the `crm.qualification.delete.single` permission.
- Restoring a soft-deleted qualification is available on this page — brings a soft-deleted qualification back and it requires the `crm.qualification.restore.single` permission.
- Permanently deleting a qualification is not available on this page — no permission is declared for it on qualifications.
- Viewing the change history of a qualification is available on this page — every qualification keeps a full version history and it requires the `crm.qualification.read.audit` permission.

### Bulk actions

| Action | Status | Permission | What it does | Require Step-Up Auth |
|--------|--------|------------|--------------|----------------------|
| **delete** | ENABLED | `crm.qualification.delete.bulk` | Marks the selected qualifications as deleted | no |
| **restore** | ENABLED | `crm.qualification.restore.bulk` | Restores the selected qualifications | no |
| **duplicate** | DISABLED | — | Duplicates the selected qualifications | no |
| **export** | DISABLED | — | Exports the list | no |

- Soft-deleting the selected qualifications is available on this page — marks the selected qualifications as deleted and it requires the `crm.qualification.delete.bulk` permission.
- Restoring the selected qualifications is available on this page — restores the selected qualifications and it requires the `crm.qualification.restore.bulk` permission.
- Duplicating the selected qualifications is not available on this page — no permission is declared for it on qualifications.
- Exporting the list is not available on this page — no permission is declared for it on qualifications.
