Create a new qualification.

The page is visible with the `access.crm.create` grant.

## Pages routes

- `/crm/qualifications` — List, search and manage all qualifications.
- `/crm/qualifications/create` — Create a new qualification. *(this page)*

## What you can do here

### How to create a new qualification
1. On the **Qualifications** list page, click **New** in the toolbar.
2. Fill in the fields below — required: **10**, **0**, **1**, **2**.
3. Click **Save** — the new qualification is created.

## Fields

| Field | Required | Notes |
|-------|----------|-------|

## Actions

| Action | Status | Permission | What it does | Require Step-Up Auth |
|--------|--------|------------|--------------|----------------------|
| **Save** | ENABLED | `crm.qualification.create.single` | Validates the form and creates the qualification | no |
| **Cancel** | ENABLED | — | Discards changes and returns to the previous page | no |

- The **Save** action is available on this page — validates the form and creates the qualification and it requires the `crm.qualification.create.single` permission.
- The **Cancel** action is available on this page — discards changes and returns to the previous page.
