Create a new consent type.

The page is visible with the `access.crm.create` grant.

## Pages routes

- `/crm/consent_types` — List, search and manage all consent types.
- `/crm/consent_types/create` — Create a new consent type. *(this page)*

## What you can do here

### How to create a new consent type
1. On the **Consent Types** list page, click **New** in the toolbar.
2. Fill in the fields below — required: **10**, **0**, **1**, **2**.
3. Click **Save** — the new consent type is created.

## Actions

| Action | Status | Permission | What it does | Require Step-Up Auth |
|--------|--------|------------|--------------|----------------------|
| **Save** | ENABLED | `crm.consent_type.create.single` | Validates the form and creates the consent type | no |
| **Cancel** | ENABLED | — | Discards changes and returns to the previous page | no |

- The **Save** action is available on this page — validates the form and creates the consent type and it requires the `crm.consent_type.create.single` permission.
- The **Cancel** action is available on this page — discards changes and returns to the previous page.
