List, search and manage all contact types.

Each row shows the Code, the Label translation, the Value kind, the Sort.

The page is visible with the `access.crm.contact_types` grant.

## Pages routes

- `/crm/contact_types` — List, search and manage all contact types. *(this page)*
- `/crm/contact_types/create` — Create a new contact type.

## What you can do here

### How to create a new contact type
1. Click **New** in the toolbar.
2. Fill in the form — required: **11**, **0**, **1**, **2**, **3**.
3. Click **Save** — the new contact type is created.

### How to delete a contact type
1. Open the row actions menu on the contact type and click **Delete**.
2. Confirm the deletion in the dialog — the contact type is soft-deleted and can be restored.

### How to restore a deleted contact type
1. Set the deleted-records filter to **Deleted only** or **All records** to show recoverable records.
2. Open the row actions menu on the contact type and click **Restore**.
3. Confirm in the dialog — the contact type is active again.

### How to view the change history of a contact type
1. Open the row actions menu on the contact type and click **Audit history**.
2. The version history of the contact type will appear on the right sheet panel.

## Actions

### Row actions

| Action | Status | Permission | What it does | Require Step-Up Auth |
|--------|--------|------------|--------------|----------------------|
| **create** | ENABLED | `crm.contact_type.create.single` | Creates a new contact type | no |
| **update** | DISABLED | `crm.contact_type.update.single` | Opens the contact type for editing | no |
| **delete** | ENABLED | `crm.contact_type.delete.single` | Marks the contact type as deleted but keeps it so it can be restored | no |
| **restore** | ENABLED | `crm.contact_type.restore.single` | Brings a soft-deleted contact type back | no |
| **purge** | DISABLED | — | Removes the contact type forever | no |
| **audit history** | ENABLED | `crm.contact_type.read.audit` | Shows the change history of the contact type | no |

- Creating a new contact type is available on this page — the create action opens the create form in the same tab and it requires the `crm.contact_type.create.single` permission.
- Editing a contact type is not available on this page — if enabled, it would require the `crm.contact_type.update.single` permission.
- Soft-deleting a contact type is available on this page — marks the contact type as deleted but keeps it so it can be restored and it requires the `crm.contact_type.delete.single` permission.
- Restoring a soft-deleted contact type is available on this page — brings a soft-deleted contact type back and it requires the `crm.contact_type.restore.single` permission.
- Permanently deleting a contact type is not available on this page — no permission is declared for it on contact types.
- Viewing the change history of a contact type is available on this page — every contact type keeps a full version history and it requires the `crm.contact_type.read.audit` permission.

### Bulk actions

| Action | Status | Permission | What it does | Require Step-Up Auth |
|--------|--------|------------|--------------|----------------------|
| **delete** | ENABLED | `crm.contact_type.delete.bulk` | Marks the selected contact types as deleted | no |

| **duplicate** | DISABLED | — | Duplicates the selected contact types | no |

- Soft-deleting the selected contact types is available on this page — marks the selected contact types as deleted and it requires the `crm.contact_type.delete.bulk` permission.
- Restoring the selected contact types is available on this page — restores the selected contact types and it requires the `crm.contact_type.restore.bulk` permission.
- Duplicating the selected contact types is not available on this page — no permission is declared for it on contact types.
- Exporting the list is not available on this page — no permission is declared for it on contact types.
