Create a new contact.

The page is visible with the `access.crm.create` grant.

## Pages routes

- `/crm/customer_contacts` — List, search and manage all contacts.
- `/crm/customer_contacts/create` — Create a new customer contact. *(this page)*

## What you can do here

### How to create a new contact
1. On the **Customer Contacts** list page, click **New** in the toolbar.
2. Fill in the fields below — required: **15**, **0**, **1**, **2**, **3**, **4**.
3. Click **Save** — the new contact is created.
