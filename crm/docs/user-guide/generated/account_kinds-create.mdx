Create a new account type.

The page is visible with the `access.crm.create` grant.

## Pages routes

- `/crm/account_kinds` — List, search and manage all account types.
- `/crm/account_kinds/create` — Create a new account kind. *(this page)*

## What you can do here

### How to create a new account type
1. On the **Account Kinds** list page, click **New** in the toolbar.
2. Fill in the fields below — required: **10**, **0**, **1**, **2**.
3. Click **Save** — the new account type is created.

## Actions

| Action | Status | Permission | What it does | Require Step-Up Auth |
|--------|--------|------------|--------------|----------------------|
| **Save** | ENABLED | `crm.account_kind.create.single` | Validates the form and creates the account type | no |
| **Cancel** | ENABLED | — | Discards changes and returns to the previous page | no |

- The **Save** action is available on this page — validates the form and creates the account type and it requires the `crm.account_kind.create.single` permission.
- The **Cancel** action is available on this page — discards changes and returns to the previous page.
