Create a new address type.

The page is visible with the `access.crm.create` grant.

## Pages routes

- `/crm/local_address_types` — List, search and manage all address types.
- `/crm/local_address_types/create` — Create a new local address type. *(this page)*

## What you can do here

### How to create a new address type
1. On the **Local Address Types** list page, click **New** in the toolbar.
2. Fill in the fields below — required: **10**, **0**, **1**, **2**.
3. Click **Save** — the new address type is created.

| Action | Status | Permission | What it does | Require Step-Up Auth |
|--------|--------|------------|--------------|----------------------|
