Create a new contact type.

The page is visible with the `access.crm.create` grant.

## Pages routes

- `/crm/contact_types` — List, search and manage all contact types.
- `/crm/contact_types/create` — Create a new contact type. *(this page)*

## What you can do here

### How to create a new contact type
1. On the **Contact Types** list page, click **New** in the toolbar.
2. Fill in the fields below — required: **11**, **0**, **1**, **2**, **3**.
3. Click **Save** — the new contact type is created.

## Actions

| Action | Status | Permission | What it does | Require Step-Up Auth |
|--------|--------|------------|--------------|----------------------|
| **Save** | ENABLED | `crm.contact_type.create.single` | Validates the form and creates the contact type | no |
| **Cancel** | ENABLED | — | Discards changes and returns to the previous page | no |

- The **Save** action is available on this page — validates the form and creates the contact type and it requires the `crm.contact_type.create.single` permission.
