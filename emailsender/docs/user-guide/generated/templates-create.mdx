Create a new email template.

This page is delivered by the owning module as a remote component — its content mounts inside the shared shell.

The page is visible with the `access.system.emailsender.templates.create` grant.

## Pages routes

- `/system/emailsender/templates` — List, search and manage all email templates.
- `/system/emailsender/templates/create` — Create a new email template. *(this page)*
- `/system/emailsender/templates/{uuid}` — View and edit an existing email template.

## What you can do here

### How to create a new email template
1. On the **Templates** list page, click **New** in the toolbar.
2. Fill in the fields below — required: **Code**, **language Iso**, **Subject**, **body Html**, **body Text**, **mjml Source**, **variables Json**.
3. Click **Save** — the new email template is created.
