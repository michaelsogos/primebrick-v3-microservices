Create a new email provider.

This page is delivered by the owning module as a remote component — its content mounts inside the shared shell.

The page is visible with the `access.system.emailsender.providers.create` grant.

## Pages routes

- `/system/emailsender/providers` — List, search and manage all email providers.
- `/system/emailsender/providers/create` — Create a new provider. *(this page)*
- `/system/emailsender/providers/{uuid}` — View and edit an existing provider.

## What you can do here

### How to create a new email provider
1. On the **Providers** list page, click **New** in the toolbar.
2. Fill in the fields below — required: **provider**, **api Key**, **api Endpoint**, **from Email**, **from Name**, **reply To**.
3. Click **Save** — the new email provider is created.

| Action | Status | Permission | What it does | Require Step-Up Auth |
