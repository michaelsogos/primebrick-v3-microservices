View and edit an existing email template.

This page is delivered by the owning module as a remote component — its content mounts inside the shared shell.

The page is visible with the `access.system.emailsender.templates` grant.

## Pages routes

- `/system/emailsender/templates` — List, search and manage all email templates.
- `/system/emailsender/templates/create` — Create a new email template.
- `/system/emailsender/templates/{uuid}` — View and edit an existing email template. *(this page)*

## What you can do here

### How to edit an email template
1. On the **Templates** list page, open the row actions menu on the email template you want to edit and click **Edit**.
2. Update the fields below — required: **Code**, **language Iso**, **Subject**, **body Html**, **body Text**, **mjml Source**, **variables Json**.
3. Click **Save** — the changes to the email template are saved.


The record opens in read mode first — click **Edit** to modify it. Concurrent edits are protected by optimistic locking: if someone else saves the email template while you are editing it, the page tells you before overwriting their changes. The form warns before discarding unsaved changes.
