# Devin Rule: Pre-Implementation Anatomy Protocol

## Trigger
- Applies whenever an AI agent implements or modifies a remote page in a
  service's `fe/` bundle, or a service-side metadata surface driving
  host-rendered anatomy (entity meta, `page_props.form`, nav, events).

## Canonical doc
**`docs/ai/pre-implementation-anatomy.md` — read it before acting.** This
file is a pointer; the normative text lives in the canonical doc.

## Enforcement
- Follow the normative body in the canonical doc — it is the contract; this
  file is only its trigger.
