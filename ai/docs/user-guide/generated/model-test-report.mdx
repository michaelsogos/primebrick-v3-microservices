The **Model Test Report** panel opens in a side sheet. It is delivered by the owning module as a remote component mounted inside the host sheet surface.

## Inputs

| Input | Notes |
|-------|-------|
| `model` | passed by the caller when the panel opens |

## Opened from

No page currently opens this panel — it is a declared module surface and can be opened programmatically via `openSheet('ai.modelTestReport')` by any page holding the matching access grant.
